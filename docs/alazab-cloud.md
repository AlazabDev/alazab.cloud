# Alazab Cloud — بوابة واحدة لكل خدمات العزب

## الهدف
يفتح الزائر alazab.cloud فيجد كل ما تقدمه العزب في مكان واحد — واضحًا وسريعًا ومنظمًا — دون معرفة مكان الاستضافة أو التقنية، ودون تسجيل. البوابة واجهة تجميع وتصفح فوق الأنظمة الموجودة، لا متصفح جديد ولا إعادة بناء.

## قرارات مُثبتة
- الدليل (الخدمات) يُدار من إعدادات البوابة: الاسم + الرابط + الأيقونة + التصنيف.
- التوجيه للأنظمة عبر الروابط فقط؛ كل بيئة مسؤولة عن مصادقتها، لا تسجيل دخول داخل البوابة.
- اللغة: عربي (RTL) افتراضي + إنجليزي (LTR) بزر تبديل.
- مدخل Frappe جاهز بعنوان يُضبط من الإعدادات (سيُزوَّدنا بالرابط).

## بنية البوابة (صفحة واحدة بأربع وجهات)

```
┌──────────────────────────────────────────────┐
│  شعار Alazab        [بحث موحد…]        ع/EN  │
├──────────────────────────────────────────────┤
│  كل الخدمات | مواقع ومعارض ومدونات |         │
│  أنظمة خاصة | بيئة Frappe                    │
├──────────────────────────────────────────────┤
│  شبكة بطاقات الخدمات (اسم + أيقونة + وصف)    │
│  البطاقة تنقل فورًا إلى الخدمة               │
├──────────────────────────────────────────────┤
│  تذييل: هوية العزب + إعدادات الدليل          │
└──────────────────────────────────────────────┘
```

- **البحث الموحد**: يرشّح الدليل أثناء الكتابة؛ خيار "ابحث في الويب" يفتح محرك بحث خارجي في تبويب جديد.
- **فتح الخدمات**: كل خدمة تُفتح في تبويب جديد (المواقع التي تمنع التضمين تفتح طبيعيًا دون iframe).
- **التصنيفان**: "عام" يظهر للجميع، و"خاص" يظهر مع علامة أن الدخول يتم عند فتح الخدمة نفسها.

## الإعدادات (دليل الخدمات)
- شاشة إعدادات لإضافة/تعديل/حذف أي خدمة: الاسم، الرابط، الأيقونة (اختيار من مجموعة رموز جاهزة أو رابط صورة)، التصنيف (عام/خاص).
- كتالوج ابتدائي مُزرَع يُستبدل بالخدمات الحقيقية؛ أي خدمة جديدة تُضاف دون إعادة تصميم الواجهة.
- التخزين محلي في المتصفح (localStorage) في هذه المرحلة — لا حاجة لخادم أو حسابات.

## الهوية
- الأزرق `#030957` والأصفر `#FFB900`، شعار Alazab، خط عربي/لاتيني متسق (IBM Plex Sans Arabic).
- استبدال كامل لمحتوى الموقع الحالي (بورتفوليو تسويق المحتوى) ببوابة Alazab Cloud.

## التفاصيل التقنية
- React + Vite SPA، مسارات: `/` (البوابة) و `/settings` (الإعدادات).
- الكتالوج في `src/data/` كقيم ابتدائية + طبقة تخزين محلي للتعديلات.
- لا يوجد backend في هذه المرحلة: لا تسجيل دخول في البوابة، والكتالوج محلي.

## خارج نطاق هذه المرحلة
- مصادقة داخل البوابة (كل نظام يصادق بنفسه عبر رابطه).
- كتالوج مشترك على قاعدة بيانات للجميع (يُرفع لاحقًا إذا احتجناه).
- تشغيل مواقع خارجية داخل جلسات خادم (iframe/Chromium) — لا حاجة ظاهرة الآن.
