# alazab.cloud

📊 PROMPT PARA O LOVABLE — CONTENT MARKETER PORTFOLIO
Template 5 — Growth System, Not Content

Crie um website de portfólio para um Content Marketer focado em crescimento, onde conteúdo é tratado como sistema estratégico, não como produção isolada.
O site deve parecer um produto de analytics / growth em produção, combinando clareza, dados e narrativa.

🎯 POSICIONAMENTO

Content Marketer / Content Strategist

Atua com:

SEO

distribuição

funil

onboarding

retenção

Foco em impacto mensurável

Público-alvo:

founders

líderes de marketing

times de produto em SaaS

🎨 IDENTIDADE VISUAL
Direção de Arte

Product-first

Interface limpa, funcional

Nada editorial, nada artístico

Visual de dashboard + case study

Cores

Fundo: branco ou cinza muito claro

Cor principal (escolher 1): azul, verde ou roxo

Tons neutros para texto e divisões

Cores só aparecem para dados e impacto

Tipografia

Headings: Space Grotesk

Corpo: Inter

Tipografia com cara de produto digital

🧩 ELEMENTO VISUAL ÚNICO (OBRIGATÓRIO)

👉 Impact Blocks

Blocos visuais fixos que mostram métricas como:

+120% Organic Traffic

+35% Qualified Leads

−28% Churn

+40% Activation

Esses blocos devem:

aparecer nos projetos

ter hierarquia visual clara

parecer componentes reutilizáveis

Estrutura

Criar 3 case studies, estruturados como experimentos de growth.

Cada case deve ter:

Contexto

Estratégia

Execução

Impacto

Case 1 — SEO Engine

Contexto: SaaS B2B

Estratégia: Conteúdo orientado a intenção

Execução: clusters + páginas pilares

Impacto:

+120% tráfego orgânico

+35% leads qualificados

Case 2 — Product Launch Content

Contexto: Lançamento de produto

Estratégia: narrativa + distribuição

Execução: landing pages, blog, email

Impacto:

aumento de conversão

awareness mensurável

Case 3 — Retention & Education

Contexto: churn elevado

Estratégia: conteúdo educacional e onboarding

Execução: emails, docs, blog

Impacto:

redução de churn

aumento de engajamento

Visual

Cards claros

Métricas grandes

Texto funcional, não inspiracional
